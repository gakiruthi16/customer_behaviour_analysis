# customer_behaviour_analysis
 Project Overview

This project analyzes customer purchasing behavior to identify patterns, customer segments, sales trends, and factors influencing revenue.

🎯 Objectives

- Analyze customer purchasing behavior
- Identify different customer segments
- Analyze sales and revenue trends
- Compare purchasing patterns across age groups
- Analyze sales across different product categories
- Create an interactive Power BI dashboard

🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- PostgreSQL
- Power BI
- Jupyter Notebook

🔄 Project Workflow

1. Data collection
2. Data cleaning and preprocessing using Python
3. Exploratory data analysis using Python
4. Business analysis using PostgreSQL
5. Data visualization using Power BI
6. Customer behavior and sales insights

📊 Dashboard

An interactive Power BI dashboard was created to visualize customer count, revenue, sales, customer segments, age groups, product categories, and other important business metrics.

🔍 Key Insights

The project provides insights into:

- Customer purchasing patterns
- Revenue trends
- Sales by product category
- Customer segmentation
- Sales by age group
- Subscription behavior
- Overall customer performance

📄 Project Files

- Jupyter Notebook – Data cleaning, preprocessing, and analysis
- SQL File – Business analysis queries using PostgreSQL
- Power BI File – Interactive dashboard
- Dataset – Customer data used for analysis
- Report – Detailed project documentation

🚀 Conclusion

This project demonstrates how Python, PostgreSQL, and Power BI can be combined to perform end-to-end customer behavior analysis and generate meaningful business insights.
